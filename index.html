02 / HOW I THINK

I live somewhere between how it works and how it feels.

My starting point was graphic design. Programming gave that curiosity a new set of tools. Now I gravitate toward projects where the interface, interaction, and underlying logic all matter.

I like experimenting, polishing the small things, and building something useful rather than stopping when it merely compiles.

✳ Functional is the baseline. Memorable is the goal.
